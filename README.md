# Nemukhina Signal Reader

**Расширяет поле возможного.**

Скилл для анализа сигналов, состояний, взаимодействий и решений в условиях неполной информации.

Работает с конкурирующими гипотезами: различает наблюдаемый сигнал и скрытое состояние, статистическую закономерность и конкретный случай, заявленную позицию и интерес, уверенность и точность, естественную реакцию и реакцию на наблюдение.

Когда данные перестают согласовываться с исходной моделью, расширяет пространство причин и помогает выбрать следующую информативную проверку.

<details>
<summary><strong>Что внутри и где применяется</strong></summary>

- **Разведывательная аналитика** — неполная информация, независимость источников, конкурирующие версии.
- **Клиническая диагностика** — дифференциальная диагностика, динамика симптомов и пересмотр исходной гипотезы.
- **Психотерапия и мотивационное интервьюирование** — амбивалентность, сопротивление, разрыв и восстановление взаимодействия.
- **Судебная психология** — память, внушаемость, качество показаний, уверенность и точность.
- **Переговорная наука** — позиции, интересы, ограничения, полномочия и уступки.
- **Продажи** — сложные корпоративные продажи, возражения, доверие и готовность к покупке.
- **Этология и теория сигналов** — достоверность сигналов, мимикрия, влияние аудитории и стратегическое поведение.
- **Байесовский вывод** — обновление вероятностей при поступлении индивидуальных данных.
- **Причинный анализ** — различение причин, корреляций и последствий вмешательств.
- **Теория разума и эпистемическое планирование** — знания и взаимные представления агентов.
- **Калибровка знаний между агентами** — точность представлений участников друг о друге.
- **Активный сбор информации** — информативные вопросы, тесты и ограниченные эксперименты.
- **Обратное планирование** — восстановление целей по действиям и анализ управления впечатлением наблюдателя.
- **Групповая статистика и индивидуальный случай** — качество класса сравнения, исключения и цена ошибочного отбора.
- **Выход за пределы исходной гипотезы** — поиск новых причинных классов, когда прежние версии не объясняют данные.

</details>

## MCP: доступ к внешним источникам

Рядом со скиллом подготовлен и проверен [MCP-сервер](./mcp-server), предоставляющий четыре инструмента только для чтения:

- поиск научных работ в Crossref;
- проверка конкретного DOI;
- поиск публичных проектов GitHub;
- проверка сведений о конкретном публичном репозитории.

**Статус:** исходный код, TypeScript, production-сборка и MCP-подключение прошли проверку в [GitHub Actions](https://github.com/marinanemukhina-lgtm/nemukhina-signal-reader/actions/workflows/mcp-ci.yml). Публичный MCP-адрес появится только после развёртывания и проверки на Vercel.

Для развёртывания откройте [Vercel — создать проект](https://vercel.com/new), импортируйте этот репозиторий, выберите имя `nemukhina-signal-reader-mcp`, корневой каталог `mcp-server` и среду **Next.js**. После успешной публикации URL MCP будет иметь вид `https://<домен-проекта>/mcp`.

Внешние данные служат доказательственным материалом с ссылками на источники, а не автоматическим подтверждением выводов.
