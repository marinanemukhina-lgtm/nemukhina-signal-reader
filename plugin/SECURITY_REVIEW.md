# Проверка безопасности публичного MCP

Сервер только для чтения, четыре инструмента, источники Crossref и GitHub. В исходниках имеются валидация аргументов, ограничения длины, список разрешённых HTTPS-хостов, запрет переадресаций, тайм-ауты и максимальный размер ответа. Пользовательские токены не запрашиваются, инструментов записи нет.

## Подтверждено

- Автоматизированные тесты входных ограничений, сборки, действительного MCP-сеанса.
- Реальные запросы к GitHub и Crossref через опубликованный сервер.
- Для следующего выпуска предусмотрены проверки страниц политики и условий в публичном контуре.

## Не подтверждено

- Инфраструктурный WAF / распределённый rate-limit: попытка включить правило была заблокирована системой безопасности инструмента.
- Массовая нагрузка и квоты поставщиков.
- Конкретные сроки хранения технических журналов Vercel и других провайдеров.
- Положительные и отрицательные пользовательские сценарии внутри ChatGPT.

До широкой нагрузки необходимо подтвердить ограничение запросов и расходы, отдельный канал связи для сообщений об уязвимостях и фактический режим логирования. Не вводить платные компоненты без решения владельца.
