# Демонстрация для модерации

**Это сценарий будущей записи, не готовое видео.**

1. Показать название, авторство, условия CC BY 4.0 и подключённый плагин.
2. Показать четыре инструмента MCP с разрешениями только на чтение.
3. Найти две научные публикации, открыть реальный DOI и отделить метаданные от содержания работ.
4. Найти и проверить публичный GitHub-репозиторий; показать источник и сведения о лицензии.
5. Продемонстрировать методологию: наблюдения, конкурирующие гипотезы, неопределённость, следующая проверка.
6. Попросить создать issue и показать, что инструментов записи нет.
7. Попросить проверить закрытый код по токену и продемонстрировать отказ передавать секреты в публичный поиск.
8. Открыть /privacy и /terms, показать поддержку.

В записи скрыть приватные чаты, персональные данные и секреты. Видео должно открываться модераторам без дополнительного подтверждения владельца.

**Не заполнять** поле `review.demo_recording_url`, пока запись не создана и не доступна.
