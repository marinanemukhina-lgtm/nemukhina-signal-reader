# Как подключить Nemukhina Signal Reader

**Nemukhina Signal Reader — методология анализа сигналов и решений в условиях неполной информации.** Она помогает работать с несколькими гипотезами, проверять основания выводов и выбирать следующую информативную проверку.

Сам Signal Reader не является отдельной программой для телефона или компьютера. Он используется внутри совместимого ИИ-приложения. **Способ подключения зависит от того, какие расширения поддерживает ваш ИИ-клиент.**

## Что выбрать

| Что вы хотите | Что подключить | Что получите |
| --- | --- | --- |
| **Полный Signal Reader:** анализировать ситуации по методологии и искать источники | **Плагин**, если ваше приложение поддерживает формат Agent Plugins 1.0 | Инструкции методологии, 13 справочных материалов и подключение к четырём инструментам поиска |
| **Только методология:** анализировать ваши данные без встроенного поиска через этот сервер | **Скилл (Skill)**, если приложение поддерживает навыки | Правила анализа Nemukhina Signal Reader и 13 справочных материалов |
| **Только поиск:** находить научные публикации и открытые разработки из своего ИИ-приложения | **MCP-подключение**, если приложение поддерживает удалённые серверы MCP по Streamable HTTP | Четыре инструмента поиска Crossref и GitHub; сама методология не устанавливается |

**Главное различие:** скилл определяет, *как анализировать информацию*; MCP даёт ИИ *доступ к внешним источникам*. Одно не заменяет другое. Для полного набора возможностей нужны обе части.

[**Скачать готовые файлы — релиз v1.3.0**](https://github.com/marinanemukhina-lgtm/nemukhina-signal-reader/releases/tag/v1.3.0)

## Вариант 1. Полный Signal Reader

Для приложения с поддержкой **Agent Plugins 1.0**:

1. Скачайте [**Nemukhina-Signal-Reader-Plugin-v1.3.0.zip**](https://github.com/marinanemukhina-lgtm/nemukhina-signal-reader/releases/download/v1.3.0/Nemukhina-Signal-Reader-Plugin-v1.3.0.zip).
2. В своём ИИ-приложении найдите функцию установки плагина из архива и выберите этот ZIP-файл.
3. Если клиент поддерживает обе части пакета, он получит методологию и адрес удалённого MCP-сервера. При необходимости подтвердите подключение сервера в настройках.
4. Попробуйте запрос: **«Разбери мою ситуацию по Nemukhina Signal Reader: отдели наблюдения от гипотез, найди альтернативные объяснения и предложи следующую проверку».**

**Важно:** ZIP предназначен для совместимых клиентов; это не обычное приложение, которое запускается открытием архива. Поддержка Agent Plugins 1.0 и автоматического подключения MCP должна быть реализована в выбранном клиенте. Совместимость с конкретными программами не сертифицирована.

## Вариант 2. Только методология

Если ваше приложение поддерживает **Skills (навыки)**:

1. Скачайте [**Nemukhina-Signal-Reader-v1.3.0.zip**](https://github.com/marinanemukhina-lgtm/nemukhina-signal-reader/releases/download/v1.3.0/Nemukhina-Signal-Reader-v1.3.0.zip) или [**skill.zip**](https://github.com/marinanemukhina-lgtm/nemukhina-signal-reader/releases/download/v1.3.0/skill.zip). Это альтернативные имена архива отдельного скилла, устанавливать оба не нужно.
2. Добавьте архив как навык способом, который поддерживает ваше ИИ-приложение.
3. Попросите ИИ применить Nemukhina Signal Reader к вашей задаче.

Скилл содержит основной файл `SKILL.md` и 13 справочных материалов. Он не подключает удалённый поиск автоматически. Если приложение не поддерживает установку Skills, можно передать `SKILL.md` и нужные материалы как файлы или инструкции, если клиент это допускает. Такое использование не равнозначно полноценной установке навыка и не гарантирует одинакового результата.

## Вариант 3. Только поиск научных работ и открытых проектов

**MCP (Model Context Protocol)** — стандарт подключения ИИ-приложений к внешним инструментам. Здесь он нужен для того, чтобы ИИ мог обращаться к публичным данным Crossref и GitHub. **Это не отдельный ИИ и не сама методология Signal Reader.**

Если в настройках вашего ИИ-клиента есть **«Добавить MCP-сервер»**, **«Удалённый MCP»** или аналогичный раздел:

1. Выберите подключение **удалённого MCP-сервера**.
2. Введите адрес сервера:

```text
https://nemukhina-signal-reader-mcp.vercel.app/mcp
```

3. Если клиент запрашивает параметры: **транспорт — Streamable HTTP**, **аутентификация — не требуется**. Название подключения можно указать `Nemukhina Signal Reader`.
4. Сохраните подключение. В списке инструментов должны появиться четыре функции:
   - `search_scientific_literature` — поиск научных публикаций по библиографической базе Crossref;
   - `inspect_doi` — проверка публикации по DOI;
   - `search_github_projects` — поиск публичных проектов на GitHub;
   - `inspect_github_project` — сведения о конкретном публичном репозитории.
5. Для проверки задайте вопрос: **«Найди две научные работы о Bayesian inverse planning и покажи их DOI и ссылки на источники».**

MCP возвращает библиографические записи и общедоступные метаданные. Он **не читает автоматически полный текст исследований, не проводит аудит исходного кода и не подтверждает истинность гипотез**. Все четыре инструмента работают только на чтение; создавать GitHub Issues или изменять репозитории через них нельзя.

При подключении **только MCP** ваш ИИ получит инструменты поиска, **но не правила Nemukhina Signal Reader**. Для использования методологии дополнительно установите скилл.

## Если подключение недоступно

В разных ИИ-приложениях настройки отличаются. Некоторые программы не принимают плагины или Skills в виде ZIP; некоторые не позволяют добавлять удалённые MCP-серверы, а корпоративные рабочие пространства могут блокировать такие подключения. Это ограничение клиента, а не архива.

Для ChatGPT наличие функции установки и подключения зависит от доступных возможностей и разрешений рабочего пространства. **Signal Reader опубликован на GitHub, но пока не одобрен как приложение общего каталога ChatGPT.** Публичный MCP-адрес нельзя вставить в обычный диалог и ожидать, что он подключится сам.

## Приватность и ограничения

Внешнему MCP-серверу передаются параметры запроса, после чего поисковые строки и идентификаторы направляются в соответствующие API **Crossref** или **GitHub**. Не передавайте пароли, токены, закрытые документы, чужие персональные данные и конфиденциальные истории. Используйте обезличенные формулировки.

Публичный сервер не требует учётной записи и не запрашивает токены пользователя. Частота запросов и доступность зависят от инфраструктуры и внешних API; отдельный инфраструктурный лимит нагрузки пока не подтверждён. Сроки хранения технических журналов внешними поставщиками также не подтверждены полностью.

## English quick start

**Choose your setup:** Install the complete plugin archive in a client that supports Agent Plugins 1.0; install the standalone Skill archive in a client that supports Skills; or connect a compatible client to the remote MCP endpoint `https://nemukhina-signal-reader-mcp.vercel.app/mcp` over Streamable HTTP, without authentication. The Skill provides the analysis workflow, while MCP provides four read-only retrieval tools for public Crossref and GitHub metadata. **MCP alone does not install the analysis methodology.** Individual client compatibility is not certified. Do not transmit personal data or credentials. GitHub release is public; ChatGPT directory approval is pending.
