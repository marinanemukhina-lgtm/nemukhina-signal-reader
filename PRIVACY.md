# Политика конфиденциальности Nemukhina Signal Reader

**Оператор:** Марина Немухина (Marina Nemukhina), разработчик Nemukhina Signal Reader.  
**Сервис:** https://nemukhina-signal-reader-mcp.vercel.app  
**Поддержка и обращения:** https://github.com/marinanemukhina-lgtm/nemukhina-signal-reader/issues

## Что делает сервис

Публичный сервер MCP предоставляет только четыре операции чтения: поиск научных работ и проверку DOI в Crossref, поиск и проверку публичных репозиториев GitHub. Сервис не требует регистрации и не запрашивает пароли или пользовательские токены. Методология анализа находится в отдельно устанавливаемом скилле; сервер возвращает данные из внешних каталогов.

## Какие данные передаются

При обращении клиента сервер получает переданные ему параметры инструмента: поисковый запрос, DOI либо имя публичного репозитория. Для выполнения запроса эти сведения направляются соответственно в Crossref или GitHub. Источник, время обращения и найденные публичные метаданные могут возвращаться обратно клиенту.

Vercel как поставщик хостинга обрабатывает техническую информацию о запросах (например, сетевые атрибуты, время, маршрут, коды ответов и данные для диагностики и защиты). Crossref и GitHub обрабатывают обращения согласно собственным правилам. Не следует считать, что отсутствие собственной базы данных означает отсутствие журналов у внешних поставщиков.

## Для каких целей

Сведения используются для выполнения выбранной операции, обработки ошибок, поддержания безопасности и доступности сервиса. Публичная версия не формирует пользовательские профили, не выполняет действия от имени пользователя в GitHub и не продаёт введённые поисковые запросы. Передача введённых поисковых параметров в Crossref или GitHub необходима для соответствующих инструментов.

## Хранение

В опубликованном исходном коде сервера нет базы данных с историей пользовательских запросов или учётными записями. Не заявляется, что хостинг или внешние API совсем не сохраняют технические журналы. Срок хранения и объём журналов зависят от выбранного плана, настроек и политик поставщиков; точная конфигурация дополнительных журналов и архивирования владельцем сервиса требует отдельной проверки. 

В отдельных частях инфраструктуры могут обрабатываться IP-адреса и другие технические идентификаторы, поэтому не следует отправлять через инструменты персональные данные, пароли, закрытые документы, медицинскую информацию либо иные секреты. Публичный поиск не предназначен для передачи конфиденциальных историй людей.

## Передача третьим сторонам

- **Vercel:** размещение и выполнение серверных запросов — https://vercel.com/legal/privacy-policy
- **Crossref:** библиографические данные — https://www.crossref.org/privacy/
- **GitHub:** публичные сведения о репозиториях — https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

При использовании клиента ChatGPT или другого ИИ-приложения дополнительно действует политика самого клиента. Условия этих поставщиков применяются отдельно.

## Права и обращения

Для вопроса об обработке информации или запроса относительно прав на данные используйте [раздел поддержки](https://github.com/marinanemukhina-lgtm/nemukhina-signal-reader/issues). **Не размещайте личные данные в публичных задачах GitHub.** Создайте обезличенное обращение с просьбой предоставить частный способ связи. Поскольку отдельная база пользовательских запросов в коде не предусмотрена, удаление данных, хранящихся у внешних поставщиков, регулируется их процедурами.
